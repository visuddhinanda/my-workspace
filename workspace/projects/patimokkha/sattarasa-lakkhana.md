# 十七要素（sattarasa lakkhaṇa）术语

《疑惑度脱》207:1317–1334 的论母（mātikā）：每条学处都按这十七个要素来分析，从 nidāna 到 vedanāttika，共十七个——
*Nidānaṃ puggalaṃ vatthuṃ, paññattividhimeva ca; Āṇattāpattināpatti-vipattiṃ aṅgameva ca. Samuṭṭhānavidhiṃ kiriyā-saññācittehi nānattaṃ; Vajjakammappabhedañca, tikadvayavidhiṃ tathā.*（207:1318–1321）

后面每条学处的末尾都会套用这一套术语，所以这里的译名需要统一。

**注意**：“三心 / 二心 / 一心”属于第 16 项（善三法），不是第 13 项。第 13 项 citta 只分 sacittaka（有心）/ acittaka（无心）。207:1333：*akusalacittavasena ekaṃ cittaṃ, kusalābyākatacittavasena dve cittāni, sabbesaṃ vasena tīṇi cittāni*。第 17 项同理：一受（苦受）/ 二受（乐、舍）/ 三受。

每条学处的套用格式（以 207:1455 卡提那学处为例）：
*Kathinasamuṭṭhānaṃ*（10 等起）, *akiriyaṃ*（11 作）, *nosaññāvimokkhaṃ*（12 想）, *acittakaṃ*（13 心）, *paṇṇattivajjaṃ*（14 罪过）, *kāyakammaṃ, vacīkammaṃ*（15 业）, *ticittaṃ*（16 三心）, *tivedanaṃ*（17 三受）

隔离列：**全部 17 个一级术语（要素名）都隔离**，标“✔ 一级”；✔ = 新建词条时用 `word=<巴利> tag=十七要素分析`，译文写 `[[巴利@十七要素分析]]`，与其他领域（阿毗达摩、经、一般用法）的同形词分开；空 = 不需要隔离（专有复合词、地名、意思各处相同的戒律词）。

来源列：`自定` = 你自己的术语词条；`公共` = WikiPali 公共术语表；`无词条` = 草稿里有标记但没有词条；`未标记` = 草稿里还没有作为术语标记过。

## 6. āpatti 罪（207:1324）

定义：*Āpattīti pubbappayogādivasena āpattibhedo*（207:1324）——这一项讲的是**罪的区分（āpattibheda）**：同一条学处里，按加行的阶段、对象、想（认知）的不同，分别犯哪一级罪，由轻到重列出来。每条学处里通常以 *ayamettha āpattibhedo*（这里的罪的区分就是这些）收尾，如 207:1335 第一巴拉基咖；没有区分时写 *āpattibhedo natthi*（207:1807、207:2030、207:2314）。

**戒条里的写法：**
- 按加行阶段：*māraṇatthāya opātakkhaṇanādīsu dukkaṭaṃ … manussamaraṇe pārājikan … Iminā nayena sabbattha payogabhedavasena āpattibhedo veditabbo*（207:1362 第三巴拉基咖：为杀而挖陷阱等犯恶作……人死犯巴拉基咖；依加行区分罪）
- 按对象：207:1335 第一巴拉基咖，同一行为按对象分别犯 巴拉基咖 / 图拉加亚 / 恶作。草稿把 *āpattibhedo* 译作“罪种分类”（207:1335-251）。
- 按想（三想）：*Tikapācittiyaṃ, … vematikassa vā dukkaṭaṃ*（207:1572）——实为 X 而作 X 想、怀疑、作非 X 想，三种情况都犯巴吉帝亚；反之作 X 想或怀疑的犯恶作。
- 按次数：*payoge payoge pācittiyaṃ*（每一加行一巴吉帝亚，16 处）、*pade pade dukkaṭaṃ*（每一步一恶作，8 处）。

## 11. kiriyā 作（五种）（207:1330）

207:1330 的定义：*atthāpatti kiriyato samuṭṭhāti, atthi akiriyato, atthi kiriyākiriyato, atthi siyā kiriyato siyā akiriyato, atthi siyā kiriyato siyā kiriyākiriyatoti.*

| # | 定义里的说法（207:1330） | 戒条套用里的写法 | 当前译名 | 来源 | 例子 | 隔离 |
|---|---|---|---|---|---|---|
| ① | kiriyato samuṭṭhāti | `kiriyaṃ` | 由做（kiriya） | 自定 | 掘地（例）；207:1477、207:1529 等 |  |
| ② | akiriyato samuṭṭhāti | `akiriyaṃ` | 未做（akiriya） | 自定 | 第一卡提那罪；207:1455 |  |
| ③ | kiriyākiriyato samuṭṭhāti | `kiriyākiriyaṃ` | 做及未做（kiriyākiriya） | 自定 | 从非亲里比库尼受衣；207:1481、207:2197 等 13 处 |  |
| ④ | siyā kiriyato siyā akiriyato | `siyā kiriyaṃ, siyā akiriyaṃ` | 有时[[kiriya]]，有时[[akiriya]] | 译法 | 受金银罪；207:1536 金银学处、207:1645 异语学处、207:1924 窃听学处 |  |
| ⑤ | siyā kiriyato siyā kiriyākiriyato | 不用 siyā，写成 `kiriyañca kiriyākiriyañca` | 有时[[kiriya]]，有时[[kiriyākiriya]] | 译法 | 造小屋罪；207:1397 造小屋学处 |  |

**结论**：④⑤ 不是另造的新词，而是把 ①②③ 加上 **siyā**（“有时”）组合起来：
- ④ 写 `siyā kiriyaṃ, siyā akiriyaṃ`，如 207:1536 金银学处：*siyā kiriyaṃ gahaṇena āpajjanato, siyā akiriyaṃ paṭikkhepassa akaraṇato*（受取时由做而犯，不拒绝时由未做而犯）。
- ⑤ 在 207:1397 造小屋学处写成 *kiriyañca, kiriyākiriyañca*，并解释：*vatthuṃ desāpetvā pamāṇātikkantaṃ vā karoto kiriyato samuṭṭhāti, adesāpetvā karoto kiriyākiriyato samuṭṭhāti*（指示了地点但超过尺寸而造，由做而犯；未经指示地点就造，由做及未做而犯）。
- 另有混合写法：207:2520 *siyā kiriyākiriyaṃ … siyā kiriyaṃ*。
- **定案**：④⑤ 不另建术语，`siyā` 译“有时”，后接 ①②③ 的术语标记。

**草稿用词问题**（207:1330）：
- 你用了 `[[kiriya@十七要素分析]]` 这种带标签的写法，可以用来区分同一个词的不同意思（kamma 业／甘马、paññatti 也可以这样处理）。
- 同一段里 ① 有时写 `[[kiriyā]]`（公共术语表，显示为“唯作”），有时写 `[[kiriya]]`（你自己的词条，显示为“由做”），需要统一。

# 比库巴蒂摩卡戒条名称目录

> 来源：《疑惑度脱》（Kaṅkhāvitaraṇī-aṭṭhakathā）比库巴蒂摩卡部分（207:1296–2159）的章节标题；正文检索范围是全书 207:1229–2713，包括比库尼部分对比库戒的回指；律藏《巴拉基咖》（Pārājikapāḷi，213）、《巴吉帝亚》（Pācittiyapāḷi，214）章节标题。
> 标题用 WikiPali next 站 `wikipali paras` 取，2026-11-18；正文用本机 `pali_texts` 表正则检索，证据句的坐标与出处链接经 next 站 `wikipali ref` 核对。
> 坐标格式 `book:paragraph`。本目录只收比库巴蒂摩卡（227 条）。只给巴利名，中文译名待定。

## 说明

- 巴蒂摩卡本文（207:3–523）只有分部标题，**没有逐条戒名**；戒名来自律藏分别和《疑惑度脱》的章节标题。
- 律藏标题形式为「X-sikkhāpadaṃ」，疑惑度脱为「X-sikkhāpadavaṇṇanā」；表里照抄原标题。
- 「两书名称」一栏：**同**＝名称相同；**拼写**＝只差 pp/p、a+a/ā、词尾 -ā/-a；**异**＝名称不同。
- 律藏众学法只分到品（7 品），没有逐条标题；灭诤两书都没有逐条标题，第一节末尾另列。
- 疑惑度脱有些标题合释几条（如「3-4. Suppaṭicchanna…」），在「合释」里注明。

## 二、《疑惑度脱》正文里对戒条的称呼

正文交叉引用戒条有三种格式：「X-sikkhāpade vuttanayena」（如 X 学处所说）、「X-e vuttanayena / vuttasadisa」（如 X 中所说 / 与 X 相同）、「X-sadisa」（同 X）。检索还补了「X-e viya / āgata / dassita …」和「X-āpatti」复合词两种格式。下面只列**用名称**引用的，**不列用序数**引用的（paṭhame、dasame、catutthasadisa、cīvaravaggassa dutiyasikkhāpada 等）。

### 2.3 等起（samuṭṭhāna）名称里的戒名

《疑惑度脱》说十三种等起「按最初制定的学处命名」（*paṭhamapaññattisikkhāpadavasena samuṭṭhānato terasa nāmāni labhanti*），[kaṅkhā.aṭṭha. 207:1329; VRI p.116](https://next.wikipali.cc/library/tipitaka/207-1299/read#1329)。所以等起名本身就是戒名：

paṭhamapārājika、adinnādāna、sañcaritta、samanubhāsana、kathina、eḷakaloma、padasodhamma、addhāna、theyyasattha、dhammadesanā、bhūtārocana、corivuṭṭhāpana、ananuññāta。

需要注意：
- **addhāna**：标题里没有这个戒名。按项目百科 [addhānasamuṭṭhāna](encyclopedia/addhānasamuṭṭhāna.md) 所引《附随》，它指巴吉帝亚 27「与比库尼约定同行道路」——也就是说，巴吉帝亚 27 在三处有三个名字：Saṃvidhāna（标题）、bhikkhuniyā saddhiṃ saṃvidhāna（207:1879）、addhāna（等起名）。
- **dhammadesanā**：这个等起名**不是**取自巴吉帝亚 7 Dhammadesanāsikkhāpada，而是取自众学 57 起「不为持伞者说法」那一组（见 [dhammadesanāsamuṭṭhāna](encyclopedia/dhammadesanāsamuṭṭhāna.md)）。同名不同指，整理目录时要分开。
- **samanubhāsana**：劝谏类诸戒的总称（《附随》217:1411 列 37 条），不是某一条戒的标题名。
- **corivuṭṭhāpana、ananuññāta**：是比库尼戒（比库尼僧始终 2、比库尼巴吉帝亚，207:2195 / 207:2607），不在比库巴蒂摩卡里。

## 五、总表（供建术语表）

- 每条戒一行；**分部**（pārājika 等）和**品**各占单独一行。
- 「戒条名称」取《疑惑度脱》标题；律藏标题不同的（含拼写不同）放进「别名」，并注「律」。巴拉基咖四条标题本来就没有 sikkhāpada，照原样列出。
- 带 sikkhāpada 的复合词保留 sikkhāpada。sikkhāpada 前面的词如果在 207、213、214 三本书的正文里**单独出现过**（任意格尾，含 -nti/-ti），就把裸词也列上，「单独出现」栏给首见段落和段落数。
- ⚠ 单独出现是按词形机械判定的，**不区分是不是在当戒名用**。kathina、patta、ovāda、joti 这类普通词单独出现，多数是一般义而不是戒名；建术语表时请按「单独出现」栏的出处判断。
- 别名后注「推断 / 待核」的，见第二节。等起名（addhāna 等）不列为别名。
- **「戒条名称」只放一个**，一律用带 sikkhāpada 的复合词（裸词常与普通词同形）；其余标题名、裸词、正文别名都放进「别名」。
- 同名戒条改用原典里能区分的名字作戒条名称：
  - 巴吉帝亚 20 → siñcanasikkhāpada（62 保留 sappāṇakasikkhāpada）
  - 巴吉帝亚 67 → mātugāmasikkhāpada（27 保留 saṃvidhānasikkhāpada）
  - 巴吉帝亚 45 → mātugāmena saddhiṃ rahonisajjasikkhāpada（复注 212:1614；30 保留 rahonisajjasikkhāpada，复注 212:300 称 bhikkhuniyā rahonisajjasikkhāpada）

  - sañciccasikkhāpada：巴吉帝亚 61、77

# glossary — 术语

保存术语相关文档：术语表、译名对照、译名取舍的讨论与依据。

建议约定：

- 一个主题或一批术语一个 Markdown 文件，例如 `vinaya-terms.md`、`dukkha.md`。
- 每个术语记录：巴利词（含词形）、采用译名、备选译名、取舍理由、出处（WikiPali 坐标 `book-paragraph`）。
- 定稿的术语可用 `wikipali` 插件写入 WikiPali 个人术语表；本目录保存讨论过程和依据。

## 现有术语表

- [`vinaya-terms.md`](vinaya-terms.md) —— 律藏术语表，1139 条（巴利 + 中文译名 + 一句话解释 + 来源），源自越南文《Pali Viet Vinaya Terms》和用户草稿译文里的戒律术语，译名跟随用户术语表。翻译 / 改稿律藏时按文件开头的“使用方法”注入提示词。

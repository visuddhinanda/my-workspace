# 注疏分类对不同读者与研究者的价值

本文基于 `README.md` 的分类方案和 4,604 片的标注，讨论每一类注释对谁有用、怎么用，以及用的时候要注意什么。

下文"素材量"一律指本次样本中，以该类为**主类**的片数，加上把它列为**副标签**的片数。全书的量大约是样本的 8–10 倍。

## 二、分读者说明

### 1. 初学巴利语者

**核心类**：G1、G2、L1；素材量 G1 824、G2 251、L1 882。

- 注释本身就是一部传统语法教材。G1 的 "…tīti X"、"…assāti X" 是活的 nirutti 与 vigraha 示范；G2 的 "karaṇe sāmivacanaṃ"、"upayogatthe karaṇavacanaṃ" 是格位用法的实例；L1 是现成的单语释义。
- 按 G 类把切片筛出来，可以编成"分级读本"：先读 L1 短训释（多数在 100 字符以内），再读 G1 词源，最后读 G3 的复合词析法和连声分析。
- 法集论义注的 G1 占 45%，是词源训练最密集的材料；中部复注的 G 类分布最均匀，适合综合练习。
- **注意**：G1 是传统词源学（nirutti），常为了说明义理而作语义词源，不等于现代历史语言学的词源。教学时要说明这一点。

### 2. 译者（包括本项目的翻译工作）

**核心类**：L1、L2、L4、L3、C1、C3、G2。

- **选词**：
  - L1、L4 给出注释传统对一个术语的同义词和本质定义，例如 "kāyaduccaritaṃ = 杀、盗、邪淫之思"。这是术语表里"定义"一栏最可靠的来源。
  - L3 告诉译者某词在此处取哪一义。试点里的 pariyāya 有 desanā、vāra、kāraṇa 三义，此处定为 kāraṇa。这正是误译的高发点。
- **定范围**：L2 说明代词、ādi、"其余" 具体指什么。这是译文要不要补出主语、宾语、列举项的依据。L2 是样本里最大的类（主类 891 片）。
- **定句意**：C3 是注释家对整句的意译，C1 交代说话者的用意。二者是判断语气和隐含意义的依据，例如世尊为了让婆罗门的心柔软而换一种说法。
- **定语法**：G2 和"连读 / 语序"（yojanā）直接解决巴利长句该怎么断、怎么连。
- **对本项目的直接用处**：
  - 在术语规则下，可以从 L1 和 L4 切片中自动抽取术语候选，和 `glossary/vinaya-terms.md` 对照，作为新术语提示的依据。
  - 翻译某个根本句时，按锚点调出所有挂到这句上的 L、C3、G2 切片，就成了一个"注释辅助翻译面板"。
- **注意**：复注的 M1 解释的是**义注**为什么那样说，不直接对应根本的意思。翻根本时，应以义注层的 L、C 类为主，复注层为辅。

### 3. 持律者与律学研究者（vinaya）

**核心类**：D3、L2、L4、A2；素材量 D3 285、A2 201。

- 律注义注的 D3 占 19%。这些"sace…pārājikaṃ / thullaccayaṃ / dukkaṭaṃ"的判定，是一部实际可用的**判例集**。按学处和情形把 D3 切片索引起来，就是一本"律注判例检索"。
- 戒律里的 L2 往往决定罪的成立条件。比如处所、器物、身体部位的界限，"陆地"包括哪里，"负物"从哪里算起，对判罪有直接影响。
- 律注的 A2 也很重要：
  - 它保存了 Mahāpaccarī、Kurundī、Andhakaṭṭhakathā 等古注的分歧意见，然后给出取舍。
  - 持律者不但要知道"结论是什么"，还要知道"有哪些不同意见、为什么取这一种"。
- **注意**：
  - A2 片里有"被破的意见"。只读片段时，可能把被否定的意见误当作定论。使用时必须连同其后的判定（D3）一起读。
  - 本文建议把 A2 拆成"评破"和"并列异说"，原因也在这里：二者的权威性不同。

### 4. 一般佛法读者与禅修者

**核心类**：C1、C2、D2、D1、例证故事。

- 对这类读者，注释里最有吸引力的是**故事、譬喻和意图**：
  - 中部义注的语境类占 22%，譬喻 5%。
  - 长老事迹、民间故事（例证故事）与禅那四喻、五盖喻，都属于这一类。
- 反过来，G、M 类对这类读者几乎都是噪音：M1 在复注层占 12–28%，G1 在法集论义注占 45%。如果把注释原样呈现给一般读者，很快就读不下去。
- **用法**：做一个"读者模式"，只显示 C、D2、D1 和 C3 类切片。注释的可读性会大幅提高，而且不需要另写白话解说。

### 5. 阿毗达摩研究者

**核心类**：L4、D4、D1、D3（论藏用法）、A2。

- 法集论注释中，L4（实质定义：lakkhaṇa、rasa、paccupaṭṭhāna 一类）与 D4（摄与不摄、计数）构成阿毗达摩的**概念体系骨架**。
- 论藏的 D3 是另一种判定：哪种心能以过去、未来、现在为所缘，哪些法属于某个三法组。这类判定可以整理成表，作为论母体系的形式化描述。
- 法集论注释里，复注、随复注之间的 A2 尤其有价值。例如关于"刹那现在能否为他心智所缘"，复注里引了 keci（即无畏山住者）之说；又如"睡眠是色还是非色"之辩，三层注释都有参与。这些是研究上座部内部教理分歧的一手材料。

### 6. 注释学与文献学研究者

**核心类**：M1、M2、A2、R、G3（校勘）、史事考证。

- **M 类就是"注释的注释学"**：
  - M1 和 M2 记录了后代注释家如何理解前代注释家的写法，比如为什么用这个词、这句话的作用是什么、这里的问句属于哪一种。
  - 本研究的数据显示，M1 的比例随层级递增：义注 0–2%，复注 12–22%，随复注 28%。这是注释体裁"自我指涉化"的量化证据。
- **A2 和 R 是失传文献的线索**：
  - 律注里大量引用的 Mahāpaccarī、Kurundī、Andhakaṭṭhakathā 等古僧伽罗注释已经失传，A2 片中的转引是重建它们的主要资料。
  - R 作为副标签出现 306 次，可以据此构建经论之间的**引用网络**。
- **G3 里的校勘条目**（脱文、异本、正读）可以汇编成一份注释家眼中的异读表，和现代校勘本对照。
- **史事考证**（制戒先后、成道后的年数）是研究注释家编年观念的材料。

### 7. 思想史与部派研究

**核心类**：A2、A1、D3、L4。

- A2 的"keci vadanti" 常常指向特定的派别或人物，比如无畏山派、某位长老。把 A2 片里被引者的身份标出来，就能画出上座部大寺派与其他派别的**分歧地图**。
- 复注之间也互相评破，例如 Vimativinodanī 批评 Sāratthadīpanī。这反映了注释传统内部的发展和立场差异，可以用来研究 12–13 世纪斯里兰卡（舍利弗之《心义灯》）与南印度朱罗地区（迦叶之《除疑》）两个律学圈的关系。
- 对于同一个根本句，比较义注、复注、随复注的 L4 定义，能看到概念如何被逐层精确化甚至改写。

### 8. 数字人文与工具开发者

**核心资产**：锚点结构、L1、G1、L4、R，以及整套标注数据。

- **词典抽取**：
  - L1（882）可以抽成"注释同义词词典"。
  - G1（824）可以抽成"注释词源词典"。
  - L4（270）可以抽成"注释定义词典"。
  - 每一条都带出处坐标（`book-paragraph-word`），可以直接接入 WikiPali 的词典和术语系统。
- **注释图谱**：锚点把根本、义注、复注、随复注连成一张有向图，再加上 R 引证，构成三藏的"解释网络"。分类可以作为图上边的类型。
- **自动分类的基准**：
  - 4,604 片的人工标注，加上 150 片独立复标（κ = 0.76），可以作为训练和评估自动分类器的数据集。
  - 0.76 也给出了人工一致性的上限参考：自动分类达到 70% 以上一致，就接近人工水平。
- **界面**：在 WikiPali 阅读界面上按分类过滤注释，就能实现前面提到的"译者面板""读者模式""判例检索"。

## 三、几条通用的使用提醒

1. **主类只代表主要功能。** 长切片常常身兼数职，查找某种功能时要同时检索主类和副标签。本文的素材量就是两者合计。
2. **人工分类一致率 78%，相邻类之间会有误差。** 误差主要出在 L2 与 L4、L1 与 G1、C3 与 L2、A2 与 D3 之间。做统计时，大类层面（L、G、C、A、D、M）比细类更可靠。
3. **藏别差异很大。** 律注、经注、论注的分布截然不同（见 `README.md` 的分布表），所以任何结论都应当分语料陈述，不宜合并成"注释一般如何"。
4. **锚点是自动生成的。** 复注直接解释根本的情况，会被挂到义注上（`alt_mula` 记录了根本候选）。做精细的逐句对照时，要人工核对锚点。

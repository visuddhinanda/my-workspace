# 律藏术语表（vinaya-terms）

> **给 agent 用的术语表。** 翻译、改稿律藏（波罗提木叉、《疑惑度脱》及其复注）时，把待译段落里出现的术语行注入提示词。

## 使用方法（agent 必读）

1. **匹配（两步，先找候选，再按语境判定）**：
   1. **找候选**：对待译巴利段落，按词干在第 1 列查找（巴利词有格变化，如 `saṅghādisesaṃ` → `saṅghādisesa`）。复合词**先整体查**；整体查不到再拆，拆出的部分也只是候选。同时查项目术语表（如 `workspace/projects/patimokkha/terms.md`）。

      ```bash
      grep -iE '^\| (saṅghādisesa|mānatta) ' workspace/glossary/vinaya-terms.md
      ```

   2. **按语境判定**：看每个候选的 **tag 列**和**解释列**，判断这个词在本段用的是不是表里这个意思：
      - **tag 为空**：律中专用词，意思各处相同，命中即注入。
      - **tag 有值**：这个词另有一般义或同形异义词，**只有语境与 tag、解释相符时才注入**，否则当普通词照常翻译，不加标记。tag 的含义：
        - `律学`：普通词，律中有专义（如 kamma 业／甘马、vihāra 住／精舍、vassa 年／雨安居、samatha 止／灭诤、abbhantara 内部／长度单位、hattha 手／肘尺、patta 已得／钵、majjhima 中间／中座比库）；
        - `十七特征`：学处十七特征语境专用，与阿毗达摩、经中同形词区分（另见 `workspace/projects/patimokkha/sattarasa-lakkhana.md`）；
        - `盗戒`、`淫戒`：只在该学处的判罪语境里是此义（如 sāhatthika「亲手」在杀戒里不是「亲手盗取」，nimittakamma 在《清净道论》邪命里是「示相求利」）；
        - `建筑`、`衣`、`卧具`、`器具`、`饰物`、`饮食`、`药`、`仓储`、`社会`：器物类词，与常见的同形异义词撞车，如 apesi（栅门／「派遣了」）、vāsī（小斧／「住者」）、miḍḍha（台阶／middha 昏沉）、cittaka（毛毯／sacittaka 的「心」）、bhaṅga（麻布／坏灭）、pūga（行会／槟榔）、pāna（浆／pāṇa 有情）。
        - `经`、`外道`、`达上`、`资具`、`威仪`：一词在律中有两个意思时用来区分各义，如 parivāsa@律学（别住）／parivāsa@外道（四个月试住）、antarāyika@律学（遮难）／antarāyika@经（障法）、nissaya@律学（依止）／nissaya@资具（四依）。
      - **同一个词有几行**（tag 不同）：按语境选其中一行；都不符合就不加标记。
      - 短词（kamma、pāda、patta、hattha、vassa、gaṇa、sīmā、vāsī、cittaka 等）不要从无关的复合词里切出来匹配。
      - 拿不准就把该词和所在句子列给用户确认，不要猜。
   只注入判定为命中的行，不要整表注入。
2. **写法**：译文里用**术语标记**（WikiPali 按术语表渲染成中文），不要把中文译名直接写进译文：
   - tag 为空 → `[[巴利词]]`；
   - tag 有值 → `[[巴利词@tag]]`，如 `[[kamma@律学]]`、`[[sāhatthika@盗戒]]`。WikiPali 上须有 word、tag 都相同的词条才能渲染；没有就提示用户新建（word、tag 建后不能改，先确认）；
   - **重定向**列有值 → 本行是异写，译文直接写该列的主词条：`[[upasampadā]]`（不写 `[[upasampada]]`），`[[aniyata@律学]]`（不写 `[[aniyatā]]`）。
3. **译名**：「中文译名」列是 WikiPali 渲染出来的中文，用来理解和核对。「解释」列是一句话解释，只用来理解语境，**不写进译文**。
4. **来源**列：
   - `草稿` = 用户译文里已用过，译名以用户术语表为准（最可靠）；
   - `推` = 按用户的译名风格从汉传译名推出（如 羯磨→甘马、比丘→比库），用户尚未确认；
   - 空 = 原始越南文字典条目的译名，用户尚未用过。
5. **表里没有的词**：如果判断它是术语，**先提示用户是否添加**，不要自行决定。
6. **WikiPali 列**：WikiPali 公共术语表里与本表不同的译名，仅供核对。

## 体例

- 来源：《Pali Viet Vinaya Terms》（Giác Nguyên 比丘编，越南文，914 条）+ 用户草稿 channel（`c75c0c2d…`，《疑惑度脱》207:1216–1434）里用过的戒律术语。由 claude-opus-5-5 整理，2026-11-14。
- 译名风格：跟随用户术语表——比库、比库尼、沙马内拉、巴拉基咖、僧始终、巴吉帝亚、图拉加亚、恶作、伍波萨他、甘马、提案、达上、马那达、别住、出罪、界限、般达咖、亲教师、巴帝摩卡。
- 标 ⚠ 的条目译名或解释待确认（见文末）。
- tag 列：2026-11-27 起增设，标出需按语境区分的词（规则见「使用方法」第 1、2 条）。
- 重定向列：同一术语有几种拼写（异写、连写／分写、长短音、ṭ／t 等）时，选一个作主词条（取规范拼写），其余行在此列写主词条（主词条有 tag 则写 `word@tag`）。主词条本行此列为空。

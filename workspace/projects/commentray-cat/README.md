# 注疏切片与分类

目标：把义注、复注切成"一句或几句"的小片，靠黑体被解释词把它挂到下一层文本上，再按解释的方式分类。

- 第一轮（试点）：巴拉基咖篇 cs_para 3–7，共 115 片，由我手工标注。见文末附录。
- 第二轮（扩大抽样）：律、经、论三部语料，共 **4,604 片**。本文前半部分写的是这一轮。

## 程序改进（相对试点）

- **去重**：一段注释常对应多个 cs_para（法集论尤其多），只做一次会切出 2,846 个重复片。现在把共享注释段落的 cs_para 合并成一个"单元"。
- **随复注层**：锚定顺序是随复注 → 复注 → 义注 → 根本。
- **匹配放宽**：忽略长短音和 ṃ/m 的区别；`vacanan·ti` 的词尾 -n 还原成 -ṃ；`…pe…` 和 `pe` 处切开；多词被解释词允许各词出现在同一句；去尾匹配时也优先选"黑体对黑体"。
- **复注直接释根本**：根本里也能匹配到的，另记 `alt_mula`（试点里的 Tathāgatassā 就属于这种）。
- **小词**：anu、api 这类小于 4 个字母的黑体不再另起切片。

锚定率（4 个字母以上的黑体）：vin1 81%，mn1 96%，abhi1 84%。没锚上的抽查下来大多不是错误，是黑体本身就不是被解释词：

- 论师、典籍名：mahāsumatthero、Andhakaṭṭhakathāyaṃ、Mahāpaccariyaṃ、Paṭisambhidāmagge、visuddhimagge
- 章节名：Sanidassanattike、Āsavagocchake、Kumbhivatthusmiṃ
- 义注讨论的词，其根本在别的 cs_para 里

## 标注方法与可靠性

- 21 个子任务，每个约 200 片，各读同一份指南和试点口径，逐片阅读后标注。模型与聊天相同。
- 合并后校验：4,604 片全部覆盖，无缺漏、无重复、无非法代码。
- **独立复标**：三部语料各随机抽 50 片，打乱顺序，由另一个子任务在不看原标注的情况下重标。

| 指标 | 值 |
|---|---|
| 主类完全一致 | **78%**（vin1 40/50、mn1 38/50、abhi1 39/50） |
| Cohen's κ | **0.76** |
| 大类一致（L/G/C/A 合并，D、M 分开） | 80% |
| 一方的主类出现在另一方的主类或副标签里 | 90% |

不一致最多的是 **M1↔X（6 例）**，全部是 `tenāha ‘X’ti` 这种引语尾巴单独成片。这是切片问题，不是分类方案的问题（见下文"待改"）。其次是 L2↔M3、C3↔L2、L2↔L4、G1↔L1/L2，各 2–3 例，都是相邻类之间的边界。

## 结论

1. **各层有固定的分工，三藏相同。**
   - 义注面向根本：词义 + 语境（叙事、意图、整句释意）。
   - 复注、随复注面向义注：词义 + 元注释。
   - 层级越高，M1（解释上一层为什么这样说）越多：义注 0–2%，复注 12–22%，随复注 28%。法集论随复注里 L2 + M1 超过一半，基本是在给复注的代词、ādi、措辞做注。
2. **义注的风格随藏别不同。**
   - 律：D3 判定占 19%，是律注独有的大类（sace…pārājikaṃ/thullaccayaṃ、某种情形如何判）。黑体常是事件名或章节名，后面跟一整段判罪。
   - 经：C 语境占 22%，叙事、人物心理、整句意译最多，D2 譬喻也只有经部常见。
   - 论：G1 词源占 45%。论母和同义词串几乎逐词用 "…tīti X / …aṭṭhena X" 训释。
3. **L2 指称限定是最大的单一类（三部都在 17–25%）。** 注释的大量工作是"这个词具体指什么、ādi 包括什么、其余是哪些"，比同义替换（L1）还多。
4. **他说与评破（A2）在律部最多（6%）。** 注释大量援引 Mahāpaccarī、Kurundī、Andhakaṭṭhakathā、gaṇṭhipada 等古注和论师之说，再给出"应审取"的结论。复注、随复注之间也有跨层评破，如随复注质疑复注、复注说义注"不随圣典"。
5. **试点的"复注被解释词多半不是义注黑体"在扩大样本中仍然成立。** 复注锚到义注的 2,064 个黑体词里，只有约 15% 落在义注的黑体词句上，约 85% 落在义注正文里。

| 副标签 `N:转用`（upacāra / kāraṇūpacāra） | 无现成代码，复标时也被单独指出 | 175-669-2~672-9、172-156 |
| 副标签 `N:疑辞`、`N:史事考证`、`N:人物介绍`、`N:章节标识`、`N:异同对照` | 各出现 3–10 次，暂时留作副标签，看更大样本 | 见 `label_stats.json` |

需要统一的口径：

- **D3 vs A2**：律注"引某师说 + 自己判定"时，主类取哪个？建议以最后给出的结论为准，有判定就标 D3、副标签 A2。
- **A1 vs M1**："Yadi evaṃ kasmā…ti āha ‘X’"（设难后引义注作答）。建议主类 M1、副标签 A1，因为它的目的是解释义注为何这样说。
- **L2 vs L4**：器物形制、身体部位的界限标 L2，"X nāma"式的戒律技术定义标 L4。这条线需要写进指南。
- **R 作主类**：分类摄属大量引经时（如漏的一至七种），建议仍以 D4 为主、R 作副标签。

## 附录：试点（cs_para 3–7）

数据来源：

- 段落对应：`related_paragraphs`，同一 `book_name` 下 cs_para 相同的行。
- 句子：`sentences`，channel `f4d07a00-…`。
- 黑体：在 `wbw_templates.style='bld'` 里（`sentences.content` 里没有黑体）。它的 `wid` 和句子的 `word_start/word_end` 是同一套编号；`{X}ti` 写法里，花括号内是黑体部分。
- 段落 HTML：`pali_texts.html` 里也有 `<span class="bld">`，可以用来核对。

切片规则："含黑体句 + 其后不含黑体的句子"为一片。锚定规则：黑体词去空格后，到下一层做子串匹配，优先黑体对黑体、离上一个锚点近的。

分类代码表见 `labeling_guide.md`。试点 115 片的主类分布：

- 义注（21 片）：以 C1/C2 语境和 L4 定义为主。
- 复注（94 片）：L1/L2/G1 约占六成，另有义注所没有的 M1，共 11 片。

两部复注大量逐字重复：除疑注约一半与心义灯相同。
